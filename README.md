# 바디루틴

**[바디루틴 웹사이트 바로 실행](https://namuking1.github.io/bodyroutine-planner/app/)**

체성분 측정값과 운동 수행을 함께 기록하는 독립적인 웹 앱입니다.

## 실행

`dist/`를 정적 웹 서버로 서비스합니다. 빌드나 패키지 설치가 필요하지 않습니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

## 검증

```powershell
node --test core.test.cjs focus.test.cjs report.test.cjs layout.test.cjs photo.test.cjs app.test.cjs
node --check dist/app.js
```

## 주요 기능

- 인바디 사진에서 수치 후보를 읽고 직접 확인한 후 분석 근거를 표시
- 항목 위치를 함께 읽고, 식별된 InBody270 전체 결과지에서는 그래프 숫자 영역을 확대해 재인식
- 사진 자동 입력 개수와 확인이 필요한 빈 항목을 구분해 표시
- 숫자 비율이 없는 부위별 ‘표준 이하·표준·표준 이상’ 평가를 원문 범주로 확인·저장
- 결과지 조절량과 확인된 참고값에 따라 실제 근력·유산소 구성 변경
- 확인된 체중 대비 하단 제지방 비율을 팔·코어·하체 동작 우선순위에 반영
- 명시적 분석 적용과 해제, 원본 기록 변경 시 이전 분석 자동 중단

- 앞면·뒷면 신체 지도에서 7개 부위를 선택하는 바디 포커스
- 부위·기구·경험·시간별 추천과 추천 근거
- 추천 세트 수를 유지해 오늘 루틴에 담기, 중복 방지와 실제 수행 기록 연결

- 최신 체중·골격근량·체지방률, 직전 측정과의 비교
- 실제 측정일 간격을 반영한 지표별 추세 그래프와 기간 필터
- 사진 OCR 후보값 입력 및 사용자 확인, 직접 입력·수정·삭제
- 사용자가 설정한 체성분 목표와 진행률
- 목표·경험·주당 일수·운동 시간·장소·기구별 주간 루틴
- 날짜별 운동 완료, 실제 세트·횟수·중량·시간 기록, 동작 설명
- JSON 백업 내보내기·병합 가져오기
- 실제 데이터와 저장 공간을 공유하지 않는 샘플 체험

## 데이터

이 브라우저의 localStorage `bodyroutine.app.v3`에 저장합니다. 현재 스키마 버전은 5이며 날짜별 집중 운동 계획과 확인한 결과지 추가 정보, 분석 적용 상태를 함께 보관합니다. 이전 `bodyroutine.records.v1` 기록도 읽으며, 과거 기록에 없는 키·나이를 추정해 채우지 않습니다. 저장 공간을 사용할 수 없으면 현재 화면에 임시 반영하고 경고합니다. 기기를 바꾸려면 JSON 백업을 내보내고 새 기기에서 가져와야 합니다.

샘플 체험은 메모리에서만 실행합니다. 샘플 백업을 실제 기록으로 가져올 수 없습니다. 인바디 계정·기기·공식 점수·기준 범위와 연결되지 않습니다. 체성분으로 근력이나 질환을 판정하지 않습니다. 추가 정보는 measurement.report에 저장하며, 사진 자체와 OCR 원문은 저장하지 않습니다. 분석 적용은 수동 목표 설정과 분리해 기록을 고치거나 적용을 해제할 때 원래의 수동 조건으로 되돌아갑니다.

사진 인식은 Tesseract.js의 한국어·영어 모델을 브라우저에서 실행합니다. 인식 도구·언어 데이터 다운로드에는 인터넷이 필요하며, 사진은 앱 서버로 전송하거나 저장하지 않습니다. OCR은 후보값이므로 원본 확인 후 저장합니다. 결과지 레이아웃에 따라 직접 수정이 필요할 수 있습니다.

## 인바디 분석 규칙과 범위

`report.js`의 규칙은 제조사 운동 처방이 아닌 앱의 설명 가능한 일반 운동 가이드입니다. 확인한 근육조절 양수·지방조절 음수 방향을 우선 참고하고, 조절량이 없을 때 성인 성별 체지방률 일반 참고 범위를 사용합니다. 알 수 없는 성별이나 서로 모순되는 값에는 감량 등을 임의 적용하지 않습니다.

부위별 제지방은 순수 근육량이 아닙니다. 하단의 현재 체중 대비 비율임을 사용자가 확인해야 팔·몸통·하체 우선순위에 사용합니다. 숫자 비율 대신 근육·제지방 분석의 평가 문구를 확인한 경우에는 그 문구를 근거로 사용하며 %로 변환하지 않습니다. kg, 상단 기대치 비율, 부위별 지방 분석과 혼동하지 않습니다. 몸통으로 가슴·등·어깨를 각각 추정하지 않습니다. 비율이나 평가에 따라 중량이나 한쪽 운동량을 올리지 않습니다.

양수 근육조절과 미세한 음수 지방조절이 함께 있으면, 지방조절 절댓값이 0.5kg 이하이고 근육조절이 그 값의 5배 이상일 때 근육 증가 방향을 우선합니다. 이는 작은 수치가 전체 루틴을 감량 방향으로 바꾸던 동작을 보완한 앱 구성 규칙입니다. 의학적 기준이나 개인 목표 처방이 아니며 화면에 적용 이유를 표시합니다.

사진 인식은 기기·언어·결과지 레이아웃에 따라 다를 수 있습니다. 후보 수치와 부호를 확인해야 저장할 수 있고, 확실하게 읽지 못한 측정일도 비워 직접 확인하도록 합니다.

확대 재인식은 전체 용지가 정면으로 나온 지원 양식을 식별했을 때만 실행합니다. 잘린 사진, 다른 기기 양식, 회전·왜곡된 사진은 동일한 자동 입력을 보장하지 않습니다. 전체 인식과 확대 인식이 다르면 확인 메시지를 표시합니다. 사진 및 인식 원문은 저장하지 않으며 확인한 수치와 평가만 브라우저에 보관합니다.
